About

AS Forms 1.0.0-web

Free static browser app. Data stays in this browser (IndexedDB / localStorage). No auto-send email.

Receipt reading (OCR) runs on your device — receipts are not uploaded to a cloud OCR service. Reader files are bundled with the app and kept for offline use after the first visit.

Send to Invoice / Timesheets cannot auto-attach via mailto (browser limit). Download the file first, then Open mail app and attach it yourself. No Microsoft sign-in (no MSAL), no paid APIs.

Installed on iPhone? The Home Screen app's data is separate from Safari's — use Backup & restore to move it.

Last backup: never

Works in every browser. Export a zip with all claims, timesheets, settings, and receipt files. Restore replaces everything in this browser.

A reminder appears if you have not backed up (zip or data folder) for 28 days.

Moving to the Home Screen app on iPhone? Export a backup here in Safari, then open the Home Screen app and Restore it — the two keep separate data.
